# ⚡ Capricorn v4.0.1 — Maintenance & Isolation Update

Техническое обновление для улучшения стабильности, изоляции окружения и корректного развёртывания ассистента на чистых системах.

---

### 🛠️ Ключевые изменения
* **Оптимизация визуального слоя:** Устранено непреднамеренное параллельное отображение устаревшего окна аватара при чистой установке. Режим отображения по умолчанию строго закреплён за современным Electron-оверлеем.
* **Изоляция конфигурации:** Все модули теперь используют строго локальные относительные пути к файлам настроек (`config.json`, `games.json`). Исключена привязка к статическим системным каталогам при установке в произвольные папки и диски.
* **Чистый шаблон окружения:** Добавлен эталонный шаблон конфигурации `config.example.json` с нейтральными значениями по умолчанию.
* **Повышена надёжность лаунчера:** Доработаны скрипты запуска `run.bat` и `setup.bat` с автоматической проверкой окружения Node.js и поддержкой портативного размещения.

---

### 📦 Быстрый старт
1. Загрузите архив `capricorn-v4.0.1.zip` из блока Assets ниже.
2. Распакуйте архив в любую удобную папку.
3. Запустите `setup.bat` для проверки и установки зависимостей.
4. Запустите `run.bat` для старта ассистента.
