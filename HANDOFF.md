## 1. Обзор проекта и назначение

**Capricorn (Capri)** — это интерактивный голосовой ассистент и десктоп-компаньон для Windows 10/11, выполненный в авторской стилистике Cyberpunk: Edgerunners (Studio Trigger).

### Архитектурный стек:
* **Frontend (Визуальный оверлей и GUI):** Electron + Node.js. Отвечает за прозрачный кликабельный оверлей поверх всех окон, спрайтовую анимацию персонажа, интерактивное позиционирование (на рамке активного окна или на панели задач Windows), чат и полнофункциональный центр настроек.
* **Backend (Ядро и системные модули):** Python 3.11–3.14. Обеспечивает голосовой контур (офлайн STT через Vosk + онлайн Google STT), аппаратную эмуляцию клавиатуры и мыши (DirectInput Set 1), оркестрацию окон и приложений Windows, Edge-TTS синтез речи и подключение к LLM (Gemini API / Ollama).
* **Связь компонентов:** Локальный HTTP REST API (`localhost:47824`) + WebSocket/IPC мост.

## 2. Текущее состояние реализации (Current State)

### 2.1. Визуальная система и Центр настроек (Settings Hub)
* Реализована 3-темная дизайн-система в стилистике Cyberpunk / Studio Trigger:
  * **Soulkiller Void** (Тёмная контрастная неоновая тема);
  * **Dusk Glitch** (Мягкая пастельная неоновая тема — по умолчанию);
  * **Arasaka Lab Daylight** (Светлая контрастная манга/HUD тема).
* Полный отказ от закруглений (`border-radius: 0`) в пользу полигональных срезов (`clip-path`), микротекстуры звёздной пыли (*Stardust Static*) и cel-shaded 2D теней.
* Автономные оффлайн-шрифты (`Unbounded`, `Jura`, `JetBrains Mono`) встроены в проект и не требуют доступа в интернет.
* Центр настроек разделен на 6 секций:
  1. *⚡ Персонализация* (масштаб, поведение, место отдыха, темы, анимации);
  2. *🔊 Звук и Микрофон* (выбор устройств ввода/вывода, громкость, тембр речи);
  3. *🧠 Нейросеть (ИИ)* (выбор провайдера, модели, безопасный ввод API-ключей, Cloudflare прокси, системный промпт);
  4. *🎮 Игровой режим* (Game Hub — конструктор профилей, живой рекордер макросов, автозахват окон и кастомные иконки);
  5. *💻 Приложения и Сайты* (полноразмерный поиск, редактирование алиасов и URL-базы);
  6. *ℹ️ О системе* (версионность, аппаратный модуль, диагностика и ссылки на репозиторий).

### 2.2. Игровой движок (Game Mode & DirectInput)
* **Аппаратная эмуляция:** Скан-коды DirectInput Set 1 через Win32 API гарантируют распознавание в любых полноэкранных 3D-играх (включая игры с Easy Anti-Cheat и BattlEye).
* **Конструктор макросов:** Поддержка одиночных биндов, циклических серий повторов и многоступенчатых цепочек с миллисекундными задержками (`[Alt + A] ➔ 80 мс ➔ [Alt + W]`).
* **Живой перехват ввода:** Запись любых клавиш клавиатуры, сочетаний и кнопок мыши (`Mouse1`–`Mouse5`).
* **Изоляция фокуса:** Макросы выполняются только при подтверждении активности целевого окна игры, исключая ложные срабатывания в ОС.
* **Эталонный профиль:** Профиль `war_thunder` сохранён в `games.json` как рабочий эталон для пользователей.

### 2.3. Изоляция окружения и стабильность (версия v4.0.1)
* **Устранение «Капри из v1»:** Дефолтный режим `"ui_mode": "electron"` жёстко закреплен в `DEFAULTS`. Устаревший виджет `Avatar` (PySide6) изолирован и больше не запускается параллельно с Electron на чистых системах.
* **Устранение статических путей:** Исключены жесткие привязки к `C:\Capri\...`. Все модули фронтенда и бэкенда разрешают пути к `config.json` и `games.json` относительно рабочей директории.
* **Защита конфиденциальных данных:** Создан безопасный шаблон `config.example.json`. В коде очищены персональные адреса Cloudflare Workers и плейсхолдеры. Файлы с ключами и логами защищены `.gitignore`.
* **Защита от двойного запуска ссылок:** Встроен 4-секундный debounce в `actions.py` и `launch.js`, исключающий дублирование вкладок в браузере при одновременном вызове из чата и голосового движка.

### 2.4. CI/CD и Релизы
* Настроен GitHub Actions workflow (`.github/workflows/release.yml`).
* При публикации Git-тега (`v*`) автоматически генерируется архив `capricorn-<tag>.zip` и оформляется релиз с описанием из `RELEASE_NOTES.md`.
* Опубликованы релизы **v4.0.0** и **v4.0.1** в репозитории [capricorn_v4](https://github.com/Mintermonde/capricorn_v4/releases).

## 3. Принятые инженерные и продуктовые решения

| Вопрос / Задача | Принятое решение | Обоснование |
|---|---|---|
| **Архитектура UI** | Electron оверлей поверх экрана вместо PySide6 виджета | Высокая гибкость CSS/HTML, плавная анимация спрайтов, поддержка сложной дизайн-системы. |
| **Шрифты интерфейса** | Локальные шрифты в `visual/assets/fonts/` | Офлайн-автономность, отсутствие зависимости от Google Fonts CDN. |
| **Профиль War Thunder в `games.json`** | Оставить в репозитории как базовый пресет | Предотвращает «страх чистого листа» у новых пользователей и наглядно демонстрирует синтаксис макросов. |
| **Разделение документации** | `README.md` для продукта, `RELEASE_NOTES.md` для релизов | `README.md` остаётся чистой презентацией, а детали версий уходят в GitHub Releases. |
| **Коммерциализация текстов** | Нейтральный продуктовый язык в публичных файлах | Исключение внутренней переписки, отладочных логов и низкоуровневых технических деталей из релизных заметок. |
| **Хранение секретов** | Исключение `config.json` из Git + добавление `config.example.json` | Безопасность пользователей при клонировании и публикации в открытый доступ. |

### Средний приоритет:
3. **Расширение библиотеки игровых пресетов:**
   * Добавить из коробки базовые конфигурации для популярных игр (*Cyberpunk 2077, Counter-Strike 2, Dota 2, Apex Legends*).

   * Реализовать в окне настроек проверку статуса запущенного сервиса Ollama и выпадающий список локально скачанных моделей.

### Низкий приоритет / Технический долг:

   * Рассмотреть окончательное удаление неиспользуемого файла `avatar.py` (PySide6) после подтверждения 100% стабильности Electron-оверлея на всех конфигурациях пользователей.

## 6. Памятка по разработке и публикации обновлений

### Локальный запуск в режиме разработки:
```cmd
:: 1. Установка зависимостей (один раз)
setup.bat

:: 2. Обычный запуск приложения
run.bat

:: 3. Запуск только Electron для отладки верстки:
cd visual
npx electron . --dev
```

### Публикация нового релиза на GitHub:
1. Внести изменения в код и обновить `RELEASE_NOTES.md` под новую версию.
2. Проверить синтаксис:
   ```powershell
   py -3.14 -m py_compile main.py actions.py games.py
   node -c visual/src/main/main.js
   ```
3. Закоммитить изменения:
   ```powershell
   git add .
   git commit -m "feat: описание обновления"
   ```
4. Создать и отправить тег:
   ```powershell
   git tag -a v4.0.2 -m "Capricorn v4.0.2"
   git push origin main
   git push origin v4.0.2
   ```
5. GitHub Actions автоматически соберёт `.zip` и опубликует релиз.
